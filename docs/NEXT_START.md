## 한 줄 요약
인공지능프로그래밍실습 과제용 Windows 단독 실행 게임. 멸망한 시뮬레이션 세계를 탐험하며 단서를 모으고, 현실로 돌아와 보고서로 추론하는 횡스크롤 로그라이크. 8시간 안에 완성이 목표.

## 현재 상태
- 완료: Godot 프로젝트 생성, 이동·점프·카메라, 바닥 재질별(wet/mud) 이동 보정, 헤드리스 테스트 2개.
- 미착수: 조사·단서 수집, 전투, 선택(대화), 보고서, 현실 거점(3D), 그래픽, 사운드, 빌드.
- 설계 문서: `..\design\01_세계관_단서_설계.md` (v0.2). 세계 3개, 장소·단서·모순·추론 카드 정리.

## 환경
- 저장소: https://github.com/gr187/world-predictor (비공개, main)
- 엔진: Godot 4.7.2 (winget 설치). 내보내기 템플릿 설치됨.
- 실행 파일: `%LOCALAPPDATA%\Microsoft\WinGet\Packages\GodotEngine.GodotEngine_Microsoft.Winget.Source_8wekyb3d8bbwe\Godot_v4.7.2-stable_win64.exe`
  - 콘솔판: 같은 폴더의 `..._win64_console.exe`
- 게임 실행: `Godot_v4.7.2-stable_win64.exe --path game --windowed`
- 테스트: `Godot_v4.7.2-stable_win64_console.exe --headless --path game -s tests/test_player.gd` (test_surface.gd도 동일)
- GitHub CLI: `C:\Program Files\GitHub CLI\gh.exe` (gr187로 로그인됨)
- 유료 AI API는 사용 불가.

## 확정된 결정
- 조작: WASD + Space(점프) / 마우스(공격 예정). 상호작용 키는 미정.
- 해상도: 480x270을 임시 사용. 최종 도트 크기는 그래픽 단계에서 확정.
- 이동·점프 수치는 현재 값 유지. 환경별(비, 진흙 등)로는 다르게 한다.
- 최종 반전과 세계 간 복선은 이번 구현에서 제외.
- 그래픽은 마지막에 입힌다. 단, 주인공·캐릭터·배경은 컨셉아트 시안을 여러 개 보여 주고 확인받은 뒤 작업.
- 모든 결정은 사용자에게 검증받고 진행한다.

## 새 세션 시작 방법
1. 이 파일과 `..\design\01_세계관_단서_설계.md`를 읽는다.
2. `git pull`로 최신 상태를 확인한다.
3. 위 "다음에 할 일 1번"의 사전 질문을 사용자에게 먼저 한다.
4. 한 단계 끝날 때마다 결과를 보여 주고 다음 방향을 확인받는다.

## 참고
- 설계 문서는 저장소 밖(`인공지능프로그래밍실습\design`)에 있다. 저장소에 포함하려면 `game\design`으로 옮길지 사용자에게 먼저 묻는다.
- 코드는 노드를 스크립트로 생성하는 방식(플레이스홀더). 씬 편집기로 옮길지 여부는 그래픽 단계에서 결정.
